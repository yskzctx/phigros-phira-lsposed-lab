# Phira 0.8.2（39）ARM64 LSPosed 开发模块

作用于 org.flos.phira，模块包名 com.phira.lab.lsp。不替换或打包原版引擎，仅接受已核对版本与原生库完整 SHA-256；其他版本拒绝激活。旧0.1已撤回，当前代码与候选没有完成真机验收，不是已完成的正式交付。

已连接的代码：默认关闭的自动游玩、目标分数/准确率、Perfect/Good 随机或早晚/Bad/Miss 规则列表、全类型与单按键筛选、音量键面板、独立实验档、已有本地记录全 AP/恢复、自动会话记录冷启动恢复。规则优先级与编号/范围/列表/随机数量/连续数量均采用控制规划器。规则修改保存后下张谱面生效，预估可能因输入帧时序与原版判定产生差异，最终以原版结算为准。

自动输入走原版触摸事件与判定方法，原版生成效果、音效与成绩；不读写受保护成绩表示，不取消完整性检查。账号 RKS 由服务端返回，不直接改写。自制谱与完整皮肤包继续使用 Phira 原生导入与管理，不重复制作播放器。

保留宿主登录、网络与原版上传流程，模拟成绩可以按原版条件尝试上传，不保证接受。详见 [联网范围](../../docs/NETWORK-POLICY.md)。原版模式选择保留；模块开关每次冷启动为关闭。

实验目录为 <宿主 getFilesDir()>/phira-lab-082/，引擎文件在 data/data.json，谱面在 data/charts，皮肤在 data/respack。original-game-data-backup-v2.json 为原始数据只读备份，不要公开。旧错误层级元数据移至 legacy-layout-v1，不覆盖实际记录。退出游戏、禁用模块并冷启动可恢复原始路径；不要覆盖回原始目录或清除游戏数据。此恢复流程仍待设备验证。

## 构建

需要 JDK 17+、Python 3.11+、Android SDK platform 36 / build-tools 36.0.0、NDK 26.3，以及官方 [Xposed API 82 编译依赖](https://api.xposed.info/de/robv/android/xposed/api/82/api-82.jar)。该 API JAR 只用于编译，不打入模块。

以下路径均由构建者提供，签名文件留在源码目录之外：

```text
python build_module.py --sdk <SDK目录> --ndk <NDK目录> --xposed-api <api-82.jar> --keystore <自有签名库> --alias <别名> --password-file <本地密码文件> --out <输出目录>
```

构建脚本当前支持 Windows、Linux；其他主机需调整 NDK host 路径。它只构建模块，不下载或打包 Phira 原版 APK/资源。输出附带 SHA-256；不要提交密码文件、签名库、原版 APK、运行日志或任何私人存档。

`native/profile.h` 来自固定版本原生库的只读分析。Java 入口会校验原版版本、64 位进程与完整原生库 SHA-256；不匹配时拒绝激活。不得把当前地址套到其他 Phira 版本。

## 验证范围

组件测试覆盖目标验证与规则编码、Good 65% double 权重、组合顺序、类型筛选、临时输入恢复、独立备份与记录恢复。另用原版 ARM64 输入和几何函数机器码核对触摸布局、坐标与调用约定；没有执行完整原版 Judge 或整局结算，不能称真机可用。构建检查签名、16KB 对齐及未打包原版引擎。

仍需真实设备核对 LSPosed 加载、冷启动、所有输入规则、最终结算、音量键、原版导入与皮肤、登录网络及禁用后的原始数据恢复。没有执行任何真实账号上传。
