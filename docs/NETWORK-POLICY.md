# 本地修改版与模块的联网区别

按用户明确确认，两个 LSPosed 模块保留宿主原有登录、联网与上传流程，自动游玩、规则干预产生的成绩也允许尝试按原版流程上传。修改版仍仅限本地、不能登录账号或执行线上操作，不声明网络权限。

Phigros 模块的云调用包装器完整转交原方法，保留返回任务与结果；独立实验存储不再作为阻止同步的条件。Phira 模块不强制离线、不添加 NO_SHADER 或键盘模式；一次迁移移除旧模块强制离线设置，后续保留用户原版选择。模块自动游玩通过原版触摸输入与判定路径生成结果，Judge.update 内临时选择输入分支，返回前恢复用户原版模式位。没有通过更改外层资格判断来强行取得上传资格。

原版的成绩资格判断、账号与服务器响应、签名完整性及反作弊检查仍决定能否上传；不伪造成功，不绕过被拒绝的结果。没有进行真实账号登录或服务器写入测试，不能保证接受成绩。

0.2.2两个模块使用独立实验存储。Phira0.2.3候选按用户要求使用原版现有数据，不重定向目录，也不清空或替换账号令牌，编辑成绩前在应用内部自动备份；Phigros模块仍保持独立实验存储。本地会话成绩恢复不会撤回已上传的数据。

检查覆盖云方法完整转交、网络配置保留、存档只读备份和判定输入的作用域恢复；这些不等于已验证实际登录、联网或最终结算。修改版新增的明确用途说明目前在源码中，已公开174二进制并未因此被替换。
