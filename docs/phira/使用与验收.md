# Phira 当前修复候选

0.2.3针对0.2.2后用户报告的密集谱/特殊谱漏判和误触暂停进行修复；自研自动游玩保留，新增原版存档直连与修改前备份。完整步骤、自动与手动恢复方式见[0.2.3安装说明](../INSTALL-v0.2.3.md)，构建和当前实现见[模块README](../../modules/phira/README.md)。

先确认模块菜单显示原版存档直连（已备份），在没有额外非完美规则时核对默认AP、此前误触暂停的密集黄键谱、移动/旋转判定线及长条续判，再核对配置的Good/Miss等规则。真实手指仍应能暂停。回归没有代替这些实际游玩检查。

修改前的完整备份在宿主files/phira-module-backups/original-data-before-module.json；成绩恢复只处理记录字段，不回退账号、设置或新导入资源。禁用模块不会自动回滚已改过的原档成绩，自动会话恢复需要再次启用模块冷启动。完整数据恢复必须先强行停止游戏并保留当前文件，按安装说明执行，不公开私人备份。

0.2.2初始化修订的正向反馈只说明当时启动/启用可用，不能据此把后续判定问题称为已经验收。本次候选仍需实际谱面复测，真实账号上传未全面验收。
