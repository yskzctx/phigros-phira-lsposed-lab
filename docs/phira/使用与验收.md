# Phira 模块使用与验收

当前0.2.2已正式发行，Phira初始化修订后收到用户正向反馈；完整功能未全面验收。下载见[统一发行页](https://github.com/yskzctx/phigros-phira-lsposed-lab/releases/tag/v0.2.2)。完整接入范围、数据位置和构建见 [模块说明](../../modules/phira/README.md)。

启用时仅在 LSPosed 勾选官方 org.flos.phira 0.8.2（39）arm64，彻底结束并冷启动。入口页可启动游戏取得一次连接报告，报告时间仅代表上次启动，勾选作用域不代表成功。音量上键打开控制面板，下键收起；自动游玩每次进程冷启动默认关闭。

在选曲页设置目标或规则并保存，下张谱面使用新计划。规则支持 Perfect、Good 早/晚/随机、Bad、Miss，以及按键筛选和六种位置选择；与真实用户输入并存时结果可能受输入影响。目标值是规划目标，不覆盖最终结算分数。

请分别核对默认关闭的一局、开启后默认 AP、分数/准确率目标、各类按键 Good 早晚/Bad/Miss 与 Perfect 保护、规则重叠优先级、原版结算及音效特效、会话成绩重启恢复。原生谱面导入、完整资源包和切换继续用 Phira 原生界面测试。记录修改只操作独立实验档，冷启动恢复保留新导入文件。

模块保留登录与联网，模拟成绩可尝试原版上传；以原版和服务器是否接受为准。独立实验档的本地恢复不会撤回上传记录，不复制原始账号令牌。不要公开备份或必要日志中的凭据。

退出游戏后禁用模块，再冷启动检查原始路径和记录恢复。电脑端报告不等于上述设备步骤已通过；初始化修订后已收到用户正向反馈；上述完整设备步骤与真实上传仍未全面验收。
