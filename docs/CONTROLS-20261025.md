# 目标、规则与联网修订

Phira 的目标分数、准确率、规则列表和原版触摸输入已连接模块；Good 权重为 65%，规则支持 Perfect 保护、Good 早/晚/随机、Bad、Miss、按键类别和位置筛选。规则规划在下张谱面生效，面板统计为模块观察事件的推算，最终以原版结算为准。

原版输入事件、动画时间、坐标与 Rust Option 返回值的 ARM64 机器码调用已在主机核对；组件夹具覆盖回滚和普通谱面输入的恢复，没有执行完整 Judge 或整局游玩。不能凭这些测试宣称真实游戏效果已通过。

强制红键/黄键 Bad 后，收尾已产生 Bad 的普通音符状态，避免恢复原类型后重复产生 Perfect；受保护成绩表示不由适配器改写。此分支已做组件回归，真实动画与结算仍待设备验证。

两个模块保留宿主原版登录与上传流程，模拟成绩也允许尝试原版上传；原版资格判断与服务器响应决定接受与否。独立实验数据的本地恢复不撤回服务器记录。修改版仍仅限本地，不能登录或联网。

公开构建与私有候选的 DEX、所有原生库逐项比对相同；签名、16KB 对齐检查通过。旧候选保持撤回，当前没有新增公开模块 APK。所有真机行为、账号与服务器上传测试均未执行。
