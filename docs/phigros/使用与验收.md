# Phigros LSPosed 模块 0.2.2

这是寄生官方包的模块，尚未真机验收，按用户要求正式发布0.2.2；功能范围和未完成项见下文。

- 模块包名：`com.phigros.lab.lsp`。
- 唯一目标：`com.PigeonGames.Phigros` 主进程，4.0.1（157），arm64-v8a，以及核对过的 libil2cpp SHA-256。
- 不重新打包、签名或替换官方 APK，不包含 Unity 或 libil2cpp。
- 模块本身没有 INTERNET、SYSTEM_ALERT_WINDOW 权限。官方宿主的网络权限保留，云同步入口完整转交原版方法，不额外阻断模拟成绩的原版上传尝试，不保证服务器接受。

## 目前已实现的接入

复用 v174 的控制规划与判定代码，包括目标分数/准确率、规则、Perfect/Good 早晚、Bad/Miss、音符类型筛选、RKS 和历史全 AP 操作。自动游玩每次冷启动默认关闭；配置保留；开启时备份本地实验记录，下次冷启动恢复。

音量上键打开面板，下键关闭。面板挂在宿主 Activity 的窗口内，不要求修改官方清单或获取悬浮窗权限。Android 11+ 查询不到模块包时使用 Xposed 提供的模块路径加载资源。

原生章节音符图片从游戏面板导入和选择。自制章节、谱面与其皮肤从模块自身的入口管理；自制章节支持现有扩展特效、音效和颜色导入。**这两处皮肤存储目前独立，不会自动共享所选皮肤。原生章节的扩展特效、音效和判定线颜色仍未完成。**

## 原始数据保护与恢复

设计上的实验根目录是：

`/data/user/0/com.PigeonGames.Phigros/files/phigros-lab-v157/`

其中 `original-backup.xml` 是首次从正版 PlayerPrefs 只读复制的备份（正版原来没有记录时写缺席标记），`shared_prefs/` 和 `files/` 属于实验存储。匿名全 AP 种子只写入实验目录。现有实验存储不重复播种。

所有控制 Hook、存储路径 Hook、云方法适配都成功后才允许切换。任何 Hook 失败会反向回滚；若原版存档提前读取，会阻止后续实验激活。电脑测试覆盖上述失败分支，但不能据此断言真机原版数据已通过验收。

退出官方游戏后在 LSPosed 禁用模块，再冷启动，是恢复正常宿主路径的操作方案。不要把实验 PlayerPrefs 覆盖到正版目录，不要卸载或清除正版数据。尚未执行手机安装与恢复测试。

## 需要真机验收的项目

安装并只勾选官方 Phigros 后冷启动，确认模块确实加载、能进入主页/章节/收藏页、音量键与控制面板正常。关闭自动游玩测试一局，再开启按规则测试。核对结算真实判定、RKS 重启行为、会话成绩恢复、皮肤及自制谱资源路径。最后退出并禁用模块，确认原始记录及正常游戏行为恢复。

实际登录和原版上传行为必须结合设备检查核实；未完成这项验收前，不把候选标为可放心联网测试或功能全部完成的模块。

电脑端已通过的检查见 `host-verification.json`；包签名、大小、哈希与真实验收状态见 `verification.json`。
