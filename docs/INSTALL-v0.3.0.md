# Phigros / Phira LSPosed 模块 0.3.0

本页对应同一预发行周期中的两个独立 APK。两者都需要 root 和支持原生 Hook 的 LSPosed；不要同时启用同一宿主的旧实验模块。

| APK | 宿主 | 版本门槛 |
|---|---|---|
| `Phigros-Lab-LSPosed-157-arm64-v0.3.0-TEST.apk` | `com.PigeonGames.Phigros` | 4.0.1（157）arm64，且文件哈希匹配 |
| `Phira-Lab-LSPosed-0.8.3-arm64-v0.3.0-TEST.apk` | `org.flos.phira` | 0.8.3（40）arm64，且原生库匹配 |

安装模块后，在 LSPosed 中只勾选对应宿主，强行停止游戏再冷启动。模块直接使用宿主原存档；第一次启用时会先备份到宿主私有目录。不要用“清除数据”处理配置问题。音量上键打开面板，下键关闭，冷启动自动游玩默认关闭。

0.3.0新增：

- 规则位置支持随机 K 个音符，可按按键种类筛选。
- 自动游玩时可选择是否屏蔽真实触摸；关闭时真实触摸优先，只有未被宿主消费时才补自动输入。
- 成绩保护支持 S、FC、AT，并可额外设置最低保护分数。
- 保护只处理目标规划生成、且没有被显式规则锁定的判定；离保护目标越远，救判为 Perfect 的概率越高。
- 免责声明按钮改为固定浅色布局和蓝底白字，避免宿主主题把文字与背景混在一起。

两个模块不强制宿主断网，也不绕过账号、服务器、签名或反作弊校验。模拟判定会按宿主原有流程进入结算；能否上传仍由原版逻辑和服务器决定。

Phigros 4.0.1.2 尚未适配：当前工作区没有该版本官方 APK 和对应 `libil2cpp.so`，只改版本号无法验证函数范围与前缀。Phira 本轮只适配 0.8.3（40）。

本轮验证覆盖主机规则、触摸隔离、保护算法、原档备份、签名和 16KB 对齐。尚未完成真实 LSPosed 加载、整局游玩、存档恢复和上传行为验收，因此不能把此页内容解释为真机已通过。
