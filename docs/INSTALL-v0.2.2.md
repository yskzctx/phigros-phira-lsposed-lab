# 0.2.2 两模块正式发行 · 安装与数据说明

同一发行包含两个独立 APK，按游戏选择。Phigros-Lab-LSPosed-157-arm64-v0.2.2.apk作用于官方com.PigeonGames.Phigros 4.0.1（157）arm64；Phira-Lab-LSPosed-0.8.2-arm64-v0.2.2.apk作用于官方org.flos.phira 0.8.2（39）arm64。模块版本统一0.2.2/code5，同原签名，支持覆盖此前候选。

1. 保留原版与实验数据备份，直接安装对应 APK。无需分卷解压或下载源码；不要卸载或清除游戏数据。
2. 在支持原生Hook的LSPosed启用模块，仅勾选对应官方游戏。推荐作用域已写入清单；不要勾选离线共存修改版或无关应用。
3. 覆盖安装后，在系统应用设置强行停止对应游戏再启动，确保旧进程中的模块代码退出。
4. 音量上键打开控制面板，下键收起。模块自动游玩每次冷启动默认关闭；在选曲页设置目标分数、准确率或规则并保存，下一张谱面生效。
5. 规则支持Perfect、Good早/晚/随机、Bad、Miss、按键筛选、编号/范围/列表/随机数量/连续数量/全部，前面的规则优先；结果以原版结算为准。Phira面板右上“复制诊断”直接复制当前进程状态，不依赖模块入口回传。

## 独立存档为什么存在

LSPosed不要求必须独立存档。此版本选择独立实验目录，隔开历史全AP、RKS与自动会话等改动，便于恢复并保护原始记录。

Phigros目录为 <宿主files>/phigros-lab-v157/，其中original-backup.xml为原始PlayerPrefs只读备份，匿名种子只初始化实验目录。Phira目录为 <宿主files>/phira-lab-082/，原始只读备份为original-game-data-backup-v2.json，实际引擎数据位于data/data.json，资源位于data/charts和data/respack。

当前不会自动复制原始账号令牌、完整谱面索引或将实验数据覆盖回原档。Phira需要在实验环境内通过原版导入器重新导入谱面和资源包，需要登录时自行走原版流程。以原档为基础可以通过将本地记录及相关资源显式复制到实验目录实现，但本次没有增加该迁移入口，避免改变刚确认可用的存储逻辑。

退出游戏，在LSPosed禁用模块并冷启动，即恢复原始数据路径；不要清空游戏数据或将实验备份覆盖原始目录。自动会话的本地成绩在冷启动恢复，配置和新导入资源保留；本地恢复不撤回已上传到服务器的记录。

## 联网及限制

两个模块保留原版登录与网络，模拟成绩也可按原版条件尝试上传，不保证接受；不取消账号、服务器、签名、完整性或反作弊检查。此策略与无网络权限的离线修改版分开。

Phira初始化顺序修订后已收到用户正向反馈，未进行全部规则、结算、网络行为的全面验收。Phigros模块未做真机验收，按用户明确要求正式发布，不标为已测通过。电脑端检查包括JVM/C回归、原生输入/几何函数、签名、16KB对齐、公开源码构建一致与文件哈希；不代表全设备兼容。

Phigros原生章节扩展特效/音效/判定线颜色仍未完成，宿主与自制章节皮肤存储独立。Phira账号RKS不直接修改，自制谱/完整皮肤使用原版管理。所有目标为规划值，不能保证精确命中。

下载异常先核对SHA256SUMS.txt，哈希不一致仅重下相应文件。源码压缩包仅供构建者使用。反馈可发送脱敏诊断文字，不公开签名私钥、账号令牌、私人备份或完整设备日志。
